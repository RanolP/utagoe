# Player Non-goals

Utagoe does not try to win against Winamp or foobar2000 by copying every power-player feature. Utagoe's differentiator is music knowledge, provider grounding, relationship-aware listening, and reliable local playback.

## Explicit Non-goals

The following are not Utagoe goals for the current product direction:

- full skinning system
- visualizer ecosystem
- DSP plugin ecosystem
- audio converter suite
- arbitrary layout customization comparable to foobar2000
- watched-folder media library parity
- local file manager parity

## Rationale

Winamp and foobar2000 are mature local player ecosystems. Utagoe should not compete by cloning their plugin, skinning, DSP, and file-management surfaces.

Utagoe should match enough playback trust to feel like a credible music player, then differentiate through:

- Track Documents
- relation-aware listening
- preview sessions
- provider metadata grounding
- provider/stat follow-up behavior
- Home discovery feed
- managed hashed storage

## Must Still Be Good

These non-goals do not excuse weak playback basics. Utagoe still needs:

- gapless playback
- ReplayGain track gain
- responsive seek
- output device selection
- queue/playlist basics
- reliable play preparation
- clear playback error handling
